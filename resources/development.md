## Doc2X MCP 开发接入资源

- 名称：Doc2X MCP Server。
- 官方链接：[NoEdgeAI/doc2x-mcp](<https://github.com/NoEdgeAI/doc2x-mcp>)。
- 用途与适合人群：把 Doc2X 的 PDF／图片解析、文档导出能力接入基于 stdio 的 MCP 客户端与 Agent 工作流；面向需要编排文档处理任务的开发者，提供 submit／status／wait 异步工具及中文配置说明。
- 文档语言及版本：默认 README 为简体中文，另有英文版；本次查阅的 package.json 版本为 0.1.7，README 与 engines 标注 Node.js >=18，后续以官方仓库为准。
- 实际查阅日期：2026-10-17，查阅了官方 README、package.json 与 LICENSE；未安装运行或调用 API，不表示已验证运行兼容性与处理效果。
- 个人备注：NoEdgeAI 公司授权 AI 据公开资料自荐。MCP 接入层采用 MIT 许可；使用服务需自备 Doc2X 账户与 API Key，PDF／图片由云端处理，API 按开放平台规则计费，与网页版会员／额度独立，不是免费离线解析工具。
